# AI Repository List & AI Skill Guideline

Kho lưu trữ danh mục tài nguyên, tài liệu hướng dẫn và mã nguồn kỹ năng (AI Agent Skills) tích hợp cho các trợ lý lập trình thông minh.

## Tài liệu chính
- [AI_Skill_Guidline.md](./AI_Skill_Guidline.md): Hướng dẫn chi tiết 101 AI Skills, phân loại theo 6 nhóm tính năng, điều kiện kích hoạt, prompt mẫu và link repository.

## Tóm tắt các kho lưu trữ (Repositories)
1. **[rohitg00/agentmemory](https://github.com/rohitg00/agentmemory)**: Quản lý bộ nhớ dài hạn, session history, recall và git commit tracing.
2. **[earthtojake/text-to-cad](https://github.com/earthtojake/text-to-cad)**: Thiết kế CAD tham số (build123d), in 3D (OrcaSlicer/Bambu), bản vẽ 2D và robot URDF/SRDF.
3. **[GoogleCloudPlatform/datacloud-skills](https://github.com/GoogleCloudPlatform/datacloud-skills)**: Kỹ thuật dữ liệu đám mây Google BigQuery, Airflow, Dataflow, Dataproc, GCS.
4. **[obra/superpowers](https://github.com/obra/superpowers)**: Bộ khung quy chuẩn phát triển phần mềm chuẩn mực (TDD, spec, planning, subagents, code simplification).
5. **[google/antigravity](https://github.com/google/antigravity)**: Các kỹ năng lõi tích hợp sẵn trong Google Antigravity.
6. **[op7418/guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill) & [hugohe3/ppt-master](https://github.com/hugohe3/ppt-master)**: Kỹ năng tạo slide thuyết trình chuyên nghiệp.
